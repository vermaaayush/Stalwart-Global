# STALWART GROUP --- ANTIGRAVITY PROJECT MASTER DOCUMENT

## 01. Project Overview

**Project:** Stalwart Group Corporate Website\
**Website Type:** Static website\
**Experience Type:** Premium motion-rich digital experience\
**Primary Development Environment:** Antigravity\
**UI/UX Design:** Stitch AI\
**Animation / Motion:** GSAP + ScrollTrigger + supporting animation
libraries\
**Primary Audience:** International clients, suppliers, buyers,
distributors, strategic partners and business stakeholders

### Core objective

Build a premium international corporate website for Stalwart Group that
feels like an **art-directed digital experience**, not a conventional
corporate website.

The site is technically static, but the experience should feel highly
interactive and motion-led.

The website should communicate:

-   International scale
-   Business credibility
-   Cross-border sourcing
-   Trade and supply-chain capability
-   Multiple specialized businesses
-   Global network
-   Market development
-   Long-term partnerships

The website will be used as a digital company presentation for
international clients, similar in impact to a premium corporate
presentation/PPT, but with web-native interaction, storytelling and
motion.

# 24. Responsive Requirements

The website must work across:

-   Desktop
-   Laptop
-   Tablet
-   Mobile

Desktop is the primary art-directed experience.

Mobile should not simply be a scaled-down desktop.

For mobile:

-   Preserve typography hierarchy
-   Stack asymmetric layouts intelligently
-   Simplify network visualization
-   Simplify map visualization
-   Preserve the lion logo
-   Reduce motion complexity where necessary
-   Maintain fast loading

------------------------------------------------------------------------

# 25. Performance Requirements

Because the site will contain cinematic imagery and GSAP motion:

-   Optimize images
-   Use modern image formats where appropriate
-   Lazy-load below-the-fold images
-   Avoid unnecessary animation loops
-   Respect reduced-motion preferences
-   Keep JavaScript modular
-   Avoid blocking scripts
-   Avoid excessive DOM complexity
-   Use GPU-friendly transforms
-   Do not animate layout-heavy properties unnecessarily
-   Keep mobile performance a priority

The visual experience must feel premium without becoming slow.
